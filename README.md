# Blacksmith on Salesforce: enablement guide

Password-gated Phase 1 enablement guide for the Blacksmith team (SaaScend).

Only the encrypted gate (`index.html`) is published. The guide's source lives in the client repo
(`saascend-org/client-Blacksmith`, folder `enablement-guide/`); the plaintext bundle is git-ignored.

To update: edit the guide there, then run `./publish.sh` here (it asks for the password).
